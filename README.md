# 🤖 راهنمای راه‌اندازی ربات VPN فروش

---

## 📁 فایل‌های پروژه

```
vpn_bot/
├── bot.py           ← کد اصلی ربات
├── requirements.txt ← کتابخانه‌های مورد نیاز
├── .env.example     ← نمونه تنظیمات
└── db.json          ← دیتابیس (خودکار ساخته می‌شود)
```

---

## 🔧 مرحله ۱ - ساخت بات تلگرام

1. در تلگرام به `@BotFather` پیام بده
2. بنویس `/newbot`
3. یه نام و username انتخاب کن
4. توکنی مثل `7123456789:AAFxxx...` می‌ده ← این را نگه دار

---

## 🆔 پیدا کردن آیدی عددی خودت

به `@userinfobot` در تلگرام پیام بده → عدد `Id` را کپی کن

---

## ☁️ هاست رایگان - Railway.app

**بهترین گزینه رایگان برای ربات تلگرام:**

1. برو به [railway.app](https://railway.app)
2. با GitHub ثبت‌نام کن (رایگان)
3. پروژه جدید بساز → **Deploy from GitHub repo**
4. یه repo در GitHub بساز و فایل‌ها را آپلود کن
5. در Railway → **Variables** → این متغیرها را اضافه کن:

```
BOT_TOKEN    = توکن_بات
ADMIN_IDS    = آیدی_عددی_تو  (مثال: 123456789)
CARD_NUMBER  = 6037-XXXX-XXXX-XXXX
CARD_OWNER   = نام_صاحب_کارت
```

6. Railway خودکار دیپلوی می‌کنه! ✅

**محدودیت رایگان Railway:** 500 ساعت در ماه (کافیه)

## 🐍 اجرای محلی (روی کامپیوتر خودت)


## 💡 جریان کار

### مشتری می‌خره:
1. `/start` → منوی اصلی
2. 🛒 خرید سرویس جدید
3. عدد گیگ می‌فرسته (مثلاً: `20`)
4. مدت زمان می‌فرسته بین ۳۰-۹۰ روز
5. خلاصه سفارش نشون داده می‌شه
6. اگه کیف پول داشته باشه → خودکار کم می‌شه
7. اگه نه → شماره کارت نشون داده می‌شه، رسید آپلود می‌کنه
8. ادمین رسید رو می‌بینه و `/approve_ID` می‌زنه

### شارژ کیف پول:
1. 💰 کیف پول → شارژ
2. مبلغ می‌نویسه
3. رسید می‌فرسته
4. ادمین `/addbalance_USERID_AMOUNT` می‌زنه
